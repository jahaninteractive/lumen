# Example frames

Two Sony `.ARW` raw files from an a7C II, for trying Lumen without a card of your own:

- `DSC02112.ARW`: 18 October 2026, lossless compressed raw at reduced size (3584 x 2560)
- `DSC03901.ARW`: 28 October 2026, uncompressed 14-bit raw at full size (7040 x 4688)

```sh
uv run lumen import Examples
```
