          Ingest: copy a memory card safely, then import it
          
          
          Use Ingest when the photos are still on the camera's card and that card is the only copy. Ingest does three things in order:
          
          
            
            
          1. Copy. Every file on the card, videos included, is copied to your primary folder and, if you choose one, a mirror folder on a second drive.
            2. 
            
          2. Verify. Each copy is read back from its drive and its SHA-256 checksum compared with the card's. A copy that does not match is reported, never trusted.
            3. 
            
          3. Import. The verified photos in the primary folder are added to Lumen, exactly as Import would.
            4. 
          
          
          
          Lumen only reads the card; it never writes to or erases it. Hidden system files are skipped. Format the card in the camera only after the panel ends with "Every file verified on every destination."

          Import: add photos that are already on a drive
          
          
          Use Import for photos already copied off the card and backed up: a folder on your Mac or an external drive, or a single photo. Lumen reads them where they are and adds them to the contact sheet. Nothing is copied, moved, or renamed; Lumen writes only previews and sidecars into its own library.
          
          
          The originals must stay reachable: if their drive is unplugged, the contact sheet still shows previews, but export and preview refinement need the drive plugged back in. Photos still on a memory card? Use Ingest first, so a verified copy exists before you format the card.
