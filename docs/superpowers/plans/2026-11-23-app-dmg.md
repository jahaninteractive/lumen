# Lumen.app and DMG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A signed, notarized `Lumen.app` in a DMG that a non-technical photographer double-clicks: it runs the server, opens the browser, offers optional downloads from tick boxes, uninstalls itself, and stops the server on Quit.

**Architecture:** A single-file Swift/AppKit shell owns the Dock icon, the server child process, the setup window and uninstall. The app carries a relocatable Python with the `lumen` package, exiftool and both Swift helpers. Optional downloads run the same `scripts/bootstrap.sh` the checkout uses, through four new flags, so there is one download list.

**Tech Stack:** Swift (AppKit, compiled with `swiftc`, no Xcode project), zsh, Python 3.13 standalone build from `uv`, `codesign`, `notarytool`, `hdiutil`.

**Spec:** `docs/superpowers/specs/2026-11-22-app-dmg-design.md`. Read it and `AGENTS.md` first.

## Global Constraints

- Bundle identifier `au.com.jahan-interactive.lumen`. Never changes.
- Minimum macOS 13.5, Apple Silicon only. Every `swiftc` in the build uses `-target arm64-apple-macos13.5`.
- The web server stays loopback-only and fetches nothing. Only the Swift shell, by running `bootstrap.sh`, downloads.
- The app writes only to the Lumen library, `~/Library/Application Support/Lumen/` and its own copy in `/Applications`. Nothing may write inside the bundle after it is built (it is signed): the shell sets `PYTHONDONTWRITEBYTECODE=1`.
- No component name, URL, hash or size appears in Swift. They come from `bootstrap.sh --list`.
- Local AI (oMLX, models) is not offered by the app. The checkout route keeps it unchanged.
- A checkout must behave exactly as before when none of the new flags or variables is used.
- No AI vendor or model-family names in tracked files or commit messages; no co-author or session trailers. Refer to the guide as `AGENTS.md`.
- Pillow stays the only runtime Python dependency. Version goes to `0.9.0` in `src/lumen/__init__.py` and `pyproject.toml` together.
- Tests: `env -u LUMEN_OMLX_MODEL uv run python -W error -m unittest discover -s tests -v`. No test contacts a network.
- Downloads on this connection are slow (about 400 KB/s). Before any download, tell the photographer what and how big, and wait for a yes.

## Review Focus

1. **A path with a space.** `~/Library/Application Support/Lumen` has one. Every `--dest` use must survive it. Test in Task 3.
2. **A download fails or the Mac is offline.** The setup window must show the script's `Skipped:` lines, stay usable, and a second Install must resume. Manual check in Task 5.
3. **Quit or closed window during a download.** The script child must be terminated and a mounted disk image detached. Test in Task 3 (TERM runs the detach trap), manual check in Task 5.
4. **`LUMEN_HELPER_DIR` set but a helper missing.** `/api/status` reports it unavailable instead of failing. Test in Task 1.
5. **An older Lumen already running from `/Applications` when a new copy is opened from the disk image.** The new copy must not replace a running app: it says to quit the other one first. Manual check in Task 5.

### Task 3: One bootstrap for both routes

**Files:**
- Modify: `scripts/bootstrap.sh`
- Test: `tests/test_scripts.py`

**Interfaces:**
- Produces, all combinable, parsed in the existing `for arg` loop (which becomes a `while` with `shift` for the two that take a value):
  - `--dest <dir>`: replaces `$project_root/vendor` everywhere (`downloads/`, `apps/`, `data/geonames`, `data/map`) through one variable `vendor_root`.
  - `--downloads-only`: skips steps 2, 3, 4, 8 and 9 and the two "Native …" closing lines.
  - `--only <keys>`: comma separated; implies `--yes`; a component not named is skipped silently; an unknown or empty key prints the usage line and exits 2. Keys: `places`, `map`, `darktable`, `siril`, `omlx`, `fast-model`, `review-model`.
  - `--list`: prints and exits 0 before the platform check, touching no network and creating nothing. One line per component, tab separated, six fields: `key`, `label`, `size`, `purpose`, `ready|missing`, `on|off`. With `--downloads-only` the last three components are left out.

| key | label | size | purpose | default |
|---|---|---|---|---|
| `places` | Places | about 50 MB | Names the town or park a photo was taken in | on |
| `map` | Map | about 100 MB | The base map for the Map tab | on |

| `siril` | Siril | 230 MB | Stacking night-sky frames | off |
| `omlx` | oMLX | 850 MB | Runs AI advice on this Mac | on |
| `fast-model` | Fast model | 6 GB | Needed for every AI feature on this Mac | on |
| `review-model` | Review model | 16 GB | Better critique; wants 32 GB of memory | off |
