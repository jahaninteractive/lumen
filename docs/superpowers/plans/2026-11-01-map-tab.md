# Map Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Map tab that draws catalogued frames, GPX tracks and waypoints over an offline Natural Earth base map, and places unfixed frames on a track by capture time.

**Architecture:** `mapdata.py` parses GPX/GeoJSON into features and keeps a per-source-file SQLite index with an R-tree (`<library>/cache/map.sqlite`), queried by viewport bbox and zoom. `Library` gains overlay add/remove, a map photo listing and track geotagging that reuses the typed-position (`location_set`) path. `web.py` exposes read routes plus strictly validated mutation routes; `app.js` renders everything on one canvas in Web Mercator with a side panel as the accessible equivalent. Bootstrap installs the base layers; `lumen map-region` fetches Overpass detail for a bounding box on request.

**Tech Stack:** Python 3 stdlib (`sqlite3`, `xml.etree`, `json`, `urllib`, `bisect`, `math`), Pillow already present, vanilla JS `<canvas>`, zsh bootstrap, `curl`/`shasum`.

**Spec:** `docs/superpowers/specs/2026-11-01-map-tab-design.md`

## Global Constraints

- Pillow is the only runtime Python dependency; no map library in the browser.
- Loopback server; mutation routes keep `_trusted_mutation()` and strict JSON; no source paths, fingerprints or absolute paths in any map response.
- The web server never contacts the internet; only bootstrap and `lumen map-region` download, both photographer-invoked.
- Camera originals are never touched; overlay drops copy the file into `<library>/map/overlays/`.
- Never overwrite a camera fix; a typed position is replaced only with `replace: true`.
- Tests read no `vendor/data`; the Overpass client is tested with a patched `urllib.request.urlopen`; run the suite with `env -u LUMEN_OMLX_MODEL uv run python -W error -m unittest discover -s tests -v`; `node --check src/lumen/static/app.js`.
- `scripts/bootstrap.sh --check` output is pinned by `tests/test_scripts.py` and must not change.
- No AI vendor or model names in tracked files or commit messages; the shared guide is `AGENTS.md`.
- Bump `__version__` in `src/lumen/__init__.py` and `pyproject.toml` together to `0.3.0`; add a `CHANGELOG.md` line.
- Workbench colours come from the existing CSS tokens (`--charcoal`, `--graphite`, `--line`, `--muted`, `--amber`, `--cyan`).

## Review Focus

- A GPX whose `<trkpt>` lack `<time>` (exported without timestamps): it still draws, and the geotag form says the track has no times instead of offering to place frames. (Task 2 test `test_gpx_without_times_has_no_span`; Task 4 `geotag_from_track` raises `ValueError("track has no timestamps")`.)
- A GPX with several `<trkseg>` and a gap of hours between them (tracker paused at lunch): a frame shot in the gap must not be interpolated across it. (Task 4 test `test_geotag_skips_frames_in_a_segment_gap`: gap handling uses `max_gap_minutes` between bracketing points.)
- Features crossing the antimeridian (Natural Earth coastline near 180°): the bbox query must not return the whole world or drop them; store the bbox as the raw min/max and let a viewport that straddles 180° issue two queries. (Task 3 test `test_query_handles_a_viewport_across_the_antimeridian`.)
- An overlay file name with `../`, a leading dot or a slash: it is sanitised, never written outside the overlays folder, and `DELETE` of a name not in the folder is refused. (Task 4 tests `test_overlay_names_are_sanitised`, `test_remove_overlay_refuses_paths`.)
- The catalog has frames but none with a fix and no overlays: `GET /api/map/photos` returns an empty list, the tab fits the world and says "0 frames with a position", nothing throws. (Task 5 test `test_map_photos_with_no_fixes_is_empty`.)

### Task 2: GPX and GeoJSON parsing

**Files:**
- Create: `src/lumen/mapdata.py`
- Test: `tests/test_mapdata.py`

**Interfaces:**
- Produces:
  - `@dataclass(frozen=True) class Feature: kind: str; name: str; rank: int; geometry: dict` where `geometry` is GeoJSON `{"type": ..., "coordinates": ...}` with coordinates rounded to 5 decimals, and `bbox -> tuple[min_lat, max_lat, min_lon, max_lon]` property.
  - `@dataclass(frozen=True) class TrackPoint: time: datetime (UTC-aware); lat: float; lon: float; ele: float | None`.
  - `parse_gpx(text: str) -> tuple[list[Feature], list[TrackPoint]]`: tracks and routes become `kind="track"` LineString features named from `<name>` (or "Track n"), waypoints `kind="waypoint"` Points; points without `<time>` are excluded from the returned track points (sorted by time, all segments merged). Raises `ValueError("not a GPX 1.1 document")` when the root is not `{http://www.topografix.com/GPX/1/1}gpx`. `<extensions>` ignored.
  - `parse_geojson(text: str, *, source_name: str = "") -> list[Feature]`: FeatureCollection only (else `ValueError("not a GeoJSON FeatureCollection")`); `kind` from `properties["kind"]` when present, else by Natural Earth file name (`coastline`, `admin_0_boundary` -> `border`, `rivers` -> `river`, `lakes` -> `lake`, `roads` -> `road`, `populated_places` -> `place`), else by tags (`boundary` in `protected_area|national_park` or `leisure=nature_reserve` -> `park`; `waterway` -> `river`; `natural=water` -> `lake`; `highway` -> `road`), else `other`. `rank` from `scalerank` when present else 0. `name` from `properties["name"]` or `""`.
  - `decimate(coords: list[list[float]], step: float) -> list[list[float]]`: keeps a vertex when it differs from the last kept one by at least `step` degrees in lon or lat; always keeps first and last.
  - `KIND_MIN_ZOOM = {"road": 6, "place": 5, "river": 3, "lake": 3}` (unlisted kinds always drawn); `pixel_degrees(zoom: float) -> float = 360 / (256 * 2 ** zoom)`.

### Task 3: The map index

**Files:**
- Modify: `src/lumen/mapdata.py`
- Test: `tests/test_mapdata.py`

**Interfaces:**
- Consumes: Task 2.
- Produces: `class MapIndex(index_path: Path, source_dirs: list[Path])` with the `PlaceIndex` lifecycle (`__enter__/__exit__/close`, lazy `_db`):
  - Schema: `sources(path TEXT PRIMARY KEY, size INTEGER, mtime_ns INTEGER, summary TEXT)`, `features(id INTEGER PRIMARY KEY, source TEXT, kind TEXT, name TEXT, rank INTEGER, geometry TEXT)`, `features_rtree(id, min_lat, max_lat, min_lon, max_lon)`. `summary` is JSON `{"features": n, "tracks": n, "waypoints": n, "span": [iso, iso] | null}`.
  - `ensure() -> dict`: for every `*.geojson` / `*.gpx` in the source dirs (missing dirs skipped), compare `(size, mtime_ns)` to `sources`; reparse only changed or new files (delete their rows first), delete rows of vanished files. Returns `{"sources": n, "features": n, "reparsed": [names]}`. Stored `path` is the file name only, never the directory.
  - `query(min_lat, max_lat, min_lon, max_lon, *, zoom: float) -> list[dict]`: R-tree intersection, drops kinds whose `KIND_MIN_ZOOM` exceeds `zoom`, decimates coordinates with `decimate(..., pixel_degrees(zoom))` (LineString, each ring/part of Multi* and Polygon), returns `{"kind", "name", "rank", "geometry"}` only. A viewport with `min_lon > max_lon` (across 180°) queries `[min_lon, 180]` and `[-180, max_lon]` and concatenates.
  - `summaries() -> list[dict]`: `{"name": path, "summary": json}` per source.
